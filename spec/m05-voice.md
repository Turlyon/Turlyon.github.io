# 管道保护语音校验助手（M05）模块规格

> 原型文件：`modules/m05-voice.html` ｜ 对应页面清单「管道保护语音校验助手」

## 模块信息

- **对应条款**：需求概要·四（二）5
- **页面数**：3
- **优先级/节奏**：新增｜调研未列节奏，建议与管道保护稽核同批启动
- **考核指标**：—（以质检得分率与高频遗漏项改善衡量）
- **建设定位**：管道保护作业语音伴随质检：移动端工单伴随录音与交底提纲提示词、复杂噪音环境高精度转写与自定义语义质检规则、逐单质检成绩单与效能统计看板

## 调研关键发现与待明确

- **调研关键发现**：需求概要新增能力：移动端工单伴随录音+交底提纲提示词；复杂噪音环境高精度转写；后台自定义语义质检规则（关键词/意图）；每笔工单自动生成质检成绩单与效能看板
- **待明确事项**：交底提纲话术模板清单；质检规则项与评分口径

## 页面清单（每页 = 原型内一个 view，view id 已定义）

### 页面1：移动端伴随录音采集

- **view id**：`v-移动端伴随录音采集`
- **终端**：外勤APP
- **使用角色**：现场作业人员、巡检工人
- **条款**：需求概要·四（二）5（1）

**功能模块（页面承载功能）**：工单执行期间伴随录音、工单完成自动结束上传；录音界面同步展示「交底提纲」提示词，引导现场按规范话术交底；不新增独立录音操作

**关键字段/数据项**：工单号；录音文件与起止时间、时长；交底提纲提示词内容（按工单类型配置）；上传状态与弱网续传记录；录音与工单关联关系

**交互逻辑**：工单开始执行即自动启动伴随录音（可暂停续录）；录音界面固定展示交底提纲提示词供照读；工单办结自动结束录音并上传，无需人工干预；弱网环境本地暂存、网络恢复自动补传；录音与工单强关联不可跨单挂接；录音上传后进入AI质检队列

---

### 页面2：AI质检中枢·语音转写与语义质检规则配置

- **view id**：`v-AI质检中枢-语音转写与语义质检规则配置`
- **终端**：PC端（后台）
- **使用角色**：后台质检管理员、管道保护专职
- **条款**：需求概要·四（二）5（2）

**功能模块（页面承载功能）**：复杂噪音环境（施工场地）高精度语音转写；后台自定义语义质检规则（必须包含特定关键词或意图）；规则按工单类型挂接；规则版本管理

**关键字段/数据项**：转写文本与置信度、逐句时间戳；质检规则集（关键词类/意图类/必检动作类、命中判定方式、扣分权重）；规则版本与生效记录；低置信片段标记

**交互逻辑**：质检管理员按工单类型配置规则集（如监护交底必须包含安全告知要点）；转写文本逐句对齐、可点击回听原音定位；规则变更版本化生效、不追溯已出账工单；低置信片段自动标记转人工抽听，不直接计分；规则命中结果作为成绩单扣分依据

---

### 页面3：质检成绩单与效能统计看板

- **view id**：`v-质检成绩单与效能统计看板`
- **终端**：PC端
- **使用角色**：管理人员、班组长、运行站长
- **条款**：需求概要·四（二）5（3）

**功能模块（页面承载功能）**：每笔工单自动生成质检成绩单（已执行与遗漏动作逐项列示）；效能统计看板汇总平均得分率、高频遗漏项自动标红；短板回流培训与共性研判

**关键字段/数据项**：质检成绩单（总得分率、已执行动作清单、遗漏动作清单、逐项判定依据与转写原文回链）；看板指标（按人/班组/站点平均得分率、高频遗漏项排名、趋势）；与员工效能模块、培训推荐的联动记录

**交互逻辑**：工单办结录音上传完成即自动质检出分，全程不新增人工填报环节；成绩单逐项可回溯到转写文本与原始录音；高频遗漏项自动标红并推送班组长与站点；遗漏项纳入共性隐患研判视角并按能力标签匹配培训课程（口径与员工效能模块一致）

---

## 原型实现要求

- 顶部 module-top：模块名 + 优先级徽标 + segmented control 切换各页面 view
- 地图/GIS 一律用 .map-canvas CSS 示意（网格底+彩色管线+点位），禁外网地图
- 含外勤APP/移动端的页面必须用 .phone-frame 手机框呈现
- 演示数据用真实感中文数据（管段GD-XXXX、工单号、脱敏姓名），基数与调研一致
