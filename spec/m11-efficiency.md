# 员工工作效能统计与提升（M11）模块规格

> 原型文件：`modules/m11-efficiency.html` ｜ 对应页面清单「员工工作效能统计与提升」

## 模块信息

- **对应条款**：5.4.9
- **页面数**：5
- **优先级/节奏**：中｜依赖抢修统计接口二次开发（调研）
- **考核指标**：—（过程指标相对基线改善）
- **建设定位**：七类18项统一口径指标、每日六路自动归集、四类效能图表与考核报表（公示-异议-快照锁定）、AI提升建议（强制引用+四项事实校验+人工复核）、课程匹配与培训后复评

## 调研关键发现与待明确

- **调研关键发现**：现状：考核以任务完成情况为主、工作量未量化；巡检模块本身有统计（总数/完成数/百分比/日报月报）；抢修工单未与人员关联且无统计功能，从台账整理数据量大；巡查任务审核为人工抽查、未录入系统；关键规则：效能统计以现有任务记录为底、不新增填报环节；工作量计入考核的权重由各运行站自行确定
- **待明确事项**：效能考核的指标构成与权重；稽核结果是否纳入考核；培训平台的名称与接口形式

## 页面清单（每页 = 原型内一个 view，view id 已定义）

### 页面1：效能指标体系与数据归集·指标定义与口径配置

- **view id**：`v-效能指标体系与数据归集-指标定义与口径配置`
- **终端**：PC端（后台）
- **使用角色**：运行部、人力资源部
- **条款**：5.4.9

**功能模块（页面承载功能）**：七类18项效能指标定义维护（名称/公式/数据来源/周期/维度）；口径会签与版本管控；六路业务数据每日02:00自动归集与清洗剔除；分位归一与综合得分；出账校验-公示-快照锁定

**关键字段/数据项**：指标定义表（巡线覆盖率、轨迹合规率、巡检计划按期执行率、新增设备纳入率、设备台账完整率、泄漏自查率、自查作业完成率、在施工点位巡查到位率、上报单据一次合规率、维保计划按期执行率、维保凭证一次合格率、中修按期完成率、首次响应时间（中位数/90分位）、一次修复率、重复上门率、隐患转化率、隐患整改闭环率、隐患误报率）；口径五规则（定义唯一/跨期归属/分子扣减/分档统计/变更受控）；剔除五规则；归集情况（记录数/剔除数）

**交互逻辑**：口径变更须经运行部与人力资源部会签、留版本、生效后不追溯已出账月份；人员统一到工号、时间统一到日、状态统一枚举，对不齐记录挂起生成核实待办；出账前五项口径一致性校验、不通过的指标本月不出账；试算向员工公示三个工作日、可提异议；公示期满生成数据快照并锁定为考核唯一版本；综合得分=Σ(同岗位序列分位归一化得分×权重)、某类无任务不计入并重新归一权重；每个得分可逐层钻取至原始工单

### 页面2：员工效能图表·个人效能明细

- **view id**：`v-员工效能图表-个人效能明细`
- **终端**：PC端+APP
- **使用角色**：员工本人、班组长
- **条款**：5.4.9

**功能模块（页面承载功能）**：个人综合得分与最强/最弱项；七类得分与班组均值并排对照；明细指标原值+分位得分并列；逐层钻取

**关键字段/数据项**：综合得分；七类得分与班组均值（灰色参照线）；明细指标原值与分位得分；工作量与在岗情况；钻取入口（得分→指标→原始工单）；异议说明

**交互逻辑**：员工APP/Web随时查看本人当期明细；点开类别看明细、继续钻取到构成该指标的原始工单清单逐条核对；有异议提交说明、随快照留存并推送班组长核实；未出账指标存在时综合得分标注“待完整”不参与排名

### 页面3：员工效能图表·班组横向对比与排名

- **view id**：`v-员工效能图表-班组横向对比与排名`
- **终端**：PC端
- **使用角色**：运行站长、运行部
- **条款**：5.4.9

**功能模块（页面承载功能）**：同口径/同周期/同分母的班组综合与分类得分排名；并列同名次顺延；弱项分布与背景数据展示

**关键字段/数据项**：各班组综合与分类得分及名次；排名四规则（并列同名次顺延不跳号/在岗<10日不参与单列/缺项重新归一权重不按零分/口径变更当月起用不追溯）；弱项分布；背景数据（班组人数/辖区业务量/新入职占比）

**交互逻辑**：排名旁固定展示三项背景数据并标注缺项（防把业务构成差异误读为努力程度差异）；系统给出事实与差异，评价与激励由考核办法决定；跨站查看姓名按脱敏规则处理

### 页面4：员工效能图表·能力雷达与考核报表

- **view id**：`v-员工效能图表-能力雷达与考核报表`
- **终端**：PC端
- **使用角色**：员工本人、人力资源部
- **条款**：5.4.9

**功能模块（页面承载功能）**：七类能力雷达图（实线本人/虚线班组均值/低于阈值轴标红）；近六期趋势；考核报表六字段组三种格式导出；五级数据权限控制

**关键字段/数据项**：雷达图与趋势；考核报表字段组（身份/在岗/七类得分/综合/诊断/溯源）；导出格式（Excel含数据页+口径定义页+剔除记录页、PDF带口径与快照版本水印、明细数据包）；五级权限矩阵（员工本人/班组长/站长/运行部/人力资源部）

**交互逻辑**：导出随附口径定义页与快照版本、同一月份任何时候导出结果完全一致；导出历史月份沿用当时口径版本；全部查看与导出行为记入日志可追溯到人到时点；超出角色可见范围的导出请求直接拒绝不静默截断

---

### 页面5：AI能力提升建议与培训推荐

- **view id**：`v-AI能力提升建议与培训推荐`
- **终端**：PC端
- **使用角色**：班组长、培训管理岗、员工
- **条款**：5.4.9

**功能模块（页面承载功能）**：三条规则并列短板识别（低于阈值/同比下降/班组末位且低于均值）；大模型建议生成（输入受限、强制引用指标值+工单编号）；四项事实校验；班组长人工复核；课程按能力标签匹配；培训后复评闭环

**关键字段/数据项**：短板类别与命中规则；建议内容（依据引用+具体措施，每人每期≤3条）；四项校验结果（指标数值/工单编号/课程存在/用语合规）；复核结论（采纳/修改措辞/驳回+理由）；课程能力标签、历史改善度与开课安排；复评结果与“本期无需生成”输出

**交互逻辑**：输入限定在本人近四期指标、命中短板、相关工单摘要与课程目录之内；无依据不生成、禁止评价性用语与推断未提供信息；校验不通过退回重新生成；未复核的建议员工不可见；诊断结果只作能力补强不直接等同考核结论；按短板类别匹配带能力标签课程（标签匹配非关键词）、无对应课程进待补充清单不勉强匹配；培训后下一统计期自动复评：改善退出短板清单、未改善不重复推同一门课转带教/现场跟评；驳回理由按季度归集优化生成约束

## 原型实现要求

- 顶部 module-top：模块名 + 优先级徽标 + segmented control 切换各页面 view
- 地图/GIS 一律用 .map-canvas CSS 示意（网格底+彩色管线+点位），禁外网地图
- 含外勤APP/移动端的页面必须用 .phone-frame 手机框呈现
- 演示数据用真实感中文数据（管段GD-XXXX、工单号、脱敏姓名），基数与调研一致
