# 管道巡检智能排班助手（M03）模块规格

> 原型文件：`modules/m03-schedule.html` ｜ 对应页面清单「管道巡检智能排班助手」

## 模块信息

- **对应条款**：5.4.3
- **页面数**：11
- **优先级/节奏**：中｜在既有网格排班上做均衡（调研）
- **考核指标**：新增对象纳入率100%（系统硬约束）
- **建设定位**：L0-L3四级频次规则引擎+季节模版，一键周/月排班（七步可视+七项硬约束），新增通气管线与未完成任务强制纳入，合规三级校验红色阻断，隐患转化率回流优化

## 调研关键发现与待明确

- **调研关键发现**：片区内点位以百计，排班时在地图逐点选择不合理，应划定范围、范围内打点；现状问题是各区域工人忙闲不均、无负载均衡；无请假与不在岗记录，按APP签到判断在岗；日常巡检每半个月一次、两个月完成一轮全覆盖；做五休二、双休日不排任务；工作类型六类（巡检/调压箱/阀门/监护工单/单元管理/管线）
- **待明确事项**：熟悉度是否纳入排班权重；是否与管段关联以便后续导航；汛期/冬保/重保/防台期间排班规则

## 页面清单（每页 = 原型内一个 view，view id 已定义）

### 页面1：巡检策略配置中心·频次规则列表

- **view id**：`v-巡检策略配置中心-频次规则列表`
- **终端**：PC端（运行部后台）
- **使用角色**：运行部管理员
- **条款**：5.4.3

**功能模块（页面承载功能）**：L0制度下限/L1专项/L2基础/L3季节模版四级规则库；制度下限锁定；多规则命中取最密者消解；样例管段命中链预览；规则库健康度每日自检

**关键字段/数据项**：规则层级、适用条件、系数、频次结论、状态；L0下限（高压次高压≥1次/日、中压主干≥1次/周、中压支线≥1次/2周、低压≥1次/月）锁标；命中链逐条展示（L0→L2年限/泄漏史→红色管段→冬季模版，取最密后最终频次）；自检五项（僵尸规则/冗余规则/非法条件/管段漏配/命中链过深）

**交互逻辑**：L0层灰底锁标、不可编辑停用或被上层放宽，新建规则时L0层不开放选择；管段漏配为零是全网覆盖率100%的前提；规则冲突扫描为提示性质不阻断；任何变更统一经入口提交影子试排

- **view id**：`v-巡检策略配置中心-规则编辑与冲突消解`
- **终端**：PC端（运行部后台）
- **使用角色**：运行部管理员、运行部负责人
- **条款**：5.4.3

**功能模块（页面承载功能）**：因子-运算符-取值三段式条件构造器；频次系数设置；保存前五项校验（语法/取值域/L0下限/冲突扫描/影响面试算）；版本管理与审批回滚

**关键字段/数据项**：可用因子14项（管材、运行年限、管径、压力级制、道路等级、敷设环境、近36个月泄漏抢修次数、健康等级、风险排名、距在监工地距离、通气日期、上期任务状态、沿线重点用户密度、管段长度）；系数区间1.0-4.0（钢管年限≥25年取1.6、泄漏≥3次取1.8等）；影响面四项（受影响管段数/月度任务量增减/人均日工作量/下限违规数）

**交互逻辑**：取值一律从数据字典选取、不接受自由文本；系数<1.0即刻提示拒绝保存；前三项校验不通过阻断保存并定位出错位置；影子试排超时保留草稿不产出不完整结论；审批驳回附意见、草稿保留可修改重提；任一历史排班可用当时规则版本复现

### 页面3：巡检策略配置中心·季节模版管理

- **view id**：`v-巡检策略配置中心-季节模版管理`
- **终端**：PC端（运行部后台）
- **使用角色**：运行部管理员
- **条款**：5.4.3

**功能模块（页面承载功能）**：冬/夏/汛期三套模版+重大活动保供模版；按日历自动切换；时段重叠取最密者；模版系数下限锁定1.0；上年度执行回顾

**关键字段/数据项**：模版年历与适用时段（冬季12-01~02-28、夏季06-01~08-31、汛期06-15~09-30）；适用范围（压力级制多选、调压站周边200米系数2.0、距在监工地≤500米系数2.0、低洼与河道穿越段系数2.0）；切换影响预估（任务量增减、自动回抬管段数）

**交互逻辑**：重叠时段取最密者而非系数相乘；强制插入任务不受模版影响；模版切换跨越排班周期时已下发计划不回溯、新模版自下期生效；切换前7日向运行部与站长推送提醒并给出下期任务量预估；系统不接受放宽型模版（低于下限自动回抬并列出管段数）

### 页面4：智能排班引擎·一键排班生成

- **view id**：`v-智能排班引擎-一键排班生成`
- **终端**：PC端（运行站）
- **使用角色**：运行站排班员
- **条款**：5.4.3

**功能模块（页面承载功能）**：周/月度巡检任务清单一键自动生成；七步过程可视（快照冻结→规则计算→增量识别→任务池生成→地理聚类与日容量装箱→路径排序→硬约束复校验落库）；四项软约束权重调整；七项硬约束

**关键字段/数据项**：排班周期与范围；生效规则版本、季节模版、数据快照信息；软约束权重（工作量均衡0.35/路径最短0.30/地理聚集0.20/人员熟悉度0.15）；硬约束清单（频次达标/制度下限/新增通气100%纳入/未完成顺延/高压资质/人均日工时8h/节假日不排）；七步实时进度；增量强制插入明细（应纳入/已纳入/纳入率）

**交互逻辑**：支持一键生成或仅试排不落库；任一硬约束不满足即中止作业并告警运行部，不产出半成品计划；同一快照+同一规则两次生成结果完全一致；快照不完整时由排班员选择用上一份可用快照或中止；未收敛时输出当前最优可行解并标注“未达最优”

### 页面10：排班效能分析·隐患转化率分析

- **view id**：`v-排班效能分析-隐患转化率分析`
- **终端**：PC端（运行部/运行站）
- **使用角色**：运行部管理人员、运行站长
- **条款**：5.4.3

**功能模块（页面承载功能）**：隐患转化率四维统计（区域/班组/管材/频次档）；双样本比例显著性检验；样本充足性判定

**关键字段/数据项**：转化率口径（确认成立隐患数÷已完成巡检次数，分子扣撤销误报、分母不含未完成作废）；统计期汇总（巡检次数/确认隐患数/转化率/分组差异最大值/样本充足分组数）；p值与95%置信区间；近六个月趋势

**交互逻辑**：样本量低于阈值（默认800次）的分组只展示数据、标注“样本不足”不出结论不进建议；置信区间与全网均值不重叠且p<0.05判显著；按频次档分析区分“频次冗余”与“漏发现”；按班组分析指向能力问题、推送员工效能模块匹配培训（频次对人不对管段）；数据回传不完整时标注完整度提示仅供参考

## 原型实现要求

- 顶部 module-top：模块名 + 优先级徽标 + segmented control 切换各页面 view
- 地图/GIS 一律用 .map-canvas CSS 示意（网格底+彩色管线+点位），禁外网地图
- 演示数据用真实感中文数据（管段GD-XXXX、工单号、脱敏姓名），基数与调研一致
