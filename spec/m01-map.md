# 管网生命线一张图（M01）模块规格

> 原型文件：`modules/m01-map.html` ｜ 对应页面清单「管网生命线一张图」

## 模块信息

- **对应条款**：5.4.1
- **页面数**：9
- **优先级/节奏**：中｜待健康评估结果稳定后呈现（调研）
- **考核指标**：阀门关闭准确率≥90%；关阀停气范围覆盖准确率≥90%；功能演示三第1项
- **建设定位**：统一时空底图与指挥中枢：五层业务数据同源融合、四级驾驶舱下钻、一张表、四色图、盲区分析、爆管关阀与抢修调度、共性隐患研判（根因分析及策略生成）、运营决策报告

## 调研关键发现与待明确

- **调研关键发现**：当前没有满足需求的大屏，需重新建设；爆管时同屏呈现关阀方案、停气范围与最近抢修力量；健康度以健康评估结果为唯一依据；需求概要「根因分析及策略生成」已由现有「共性隐患研判（AI聚类与NLP）」页面承接
- **待明确事项**：公司层与运行站层各自关注的指标清单；各角色查看权限；大屏重建范围与呈现要求

## 页面清单（每页 = 原型内一个 view，view id 已定义）

### 页面1：公司级指挥驾驶舱

- **view id**：`v-公司级指挥驾驶舱`
- **终端**：PC端+指挥大屏
- **使用角色**：集团/子公司/分公司管理人员
- **条款**：5.4.1

**功能模块（页面承载功能）**：GIS底图与五层业务数据（设备基础、安检保养、抢修维修历史、风险隐患动态、工地信息）同源融合展示；集团-子公司-分公司-运行站四级逐级下钻；关键指标卡下钻；异常事件提醒与定位

**关键字段/数据项**：组织层级；五层图层数据及点位计数；点位五类联动信息；指标卡（如未闭环隐患126项）及统一口径定义；异常事件（级别、位置、时间）；各层数据接入状态

**交互逻辑**：登录后按组织层级与行级权限加载底图与态势；图层独立开关、可叠加，显隐即时更新计数；点击点位落问询准星锁定坐标并联动展示五类信息；点击指标卡按分公司/隐患类别等维度逐级下钻并地图高亮；组织树点击下钻，地图范围与指标口径同步收敛；点击异常事件定位到图，一级事件转入爆管关阀流程

### 页面2：运行站级指挥驾驶舱

- **view id**：`v-运行站级指挥驾驶舱`
- **终端**：PC端
- **使用角色**：运行站长、分公司管理人员
- **条款**：5.4.1

**功能模块（页面承载功能）**：管理差值分析（同周期实际值-计划值）；效能诊断（规则库输出原因判断而非仅列指标）；改进建议确认下发与按期复评

**关键字段/数据项**：五类任务（巡检、设备保养、隐患整改、工地监护、应急演练）计划值/实际值/差值；同类站横向排名与位次；同比环比；诊断结论（现象条件-原因判断-处置指向、触发规则与阈值）；改进建议（内容、依据、执行动作、生效时间、复评节点）

**交互逻辑**：进入加载本站本月差值并橙红标记超阈值项；站际对比仅在同类站间进行；规则命中输出原因判断（如连续3月欠检判排班覆盖问题），未命中不作结论；站长确认后建议转任务（排班类推送巡检排班助手、管理类进站长待办）；按周期复评，未消除重新进入诊断

### 页面3：管网运行“一张表”全景视图

- **view id**：`v-管网运行一张表全景视图`
- **终端**：PC端
- **使用角色**：管理人员、技措技改人员
- **条款**：5.4.1

**功能模块（页面承载功能）**：高中低压管网分类统计（里程与占比）；全量管段台账；多条件组合筛选；表图双向联动；Excel导出

**关键字段/数据项**：管段编号、压力等级、管径、材质、长度、投运年份、所属运行站、健康等级（四色标注）、近36个月抢修次数、最近巡检日期、当前状态；命中统计（命中数/合计长度/涉及站数）

**交互逻辑**：筛选（压力等级+材质+年份+健康等级等组合）即时过滤表格并地图高亮命中管段、自动收起其余图层；点击表格行地图定位并展开管段属性卡，点击地图管段反向定位表格行；导出Excel并记录筛选条件、导出人与时间

### 页面4：管网健康四色图

- **view id**：`v-管网健康四色图`
- **终端**：PC端
- **使用角色**：各级管理人员
- **条款**：5.4.1

**功能模块（页面承载功能）**：按管段综合评分四色渲染（红≥85/橙70-85/黄50-70/蓝<50）；红色管段清单；评分构成逐因子溯源；与隐患/工地图层叠加；按日重算

**关键字段/数据项**：综合评分；六类风险因子及权重（管龄材质0.25、腐蚀防腐0.20、第三方施工0.20、历史抢修频次0.15、周边环境0.12、压力流量工况0.08）；因子取值/权重/贡献度；四色里程占比；评分与计算时点

**交互逻辑**：切换四色图层展示各色占比；红色管段按评分降序列出；点击管段展开评分构成（逐项取值/权重/贡献度）并给出主因子与处置建议；叠加业务图层识别加剧因素；分级结果按日重算并保留时点可回溯；红橙管段输出至巡检排班频次因子、红色进入技改候选清单

### 页面5：巡检盲区覆盖分析

- **view id**：`v-巡检盲区覆盖分析`
- **终端**：PC端
- **使用角色**：运行站、分公司管理人员
- **条款**：5.4.1

**功能模块（页面承载功能）**：巡检轨迹清洗叠加管段求交计算覆盖率；盲区判定（近90天、连续60天覆盖率<60%）；三类堵点成因识别；强制补检回流排班闭环

**关键字段/数据项**：轨迹30米缓冲区；单管段覆盖率；未覆盖时长；堵点成因（排班覆盖/通行受阻/责任交界）；强制补检任务数；复算覆盖率

**交互逻辑**：系统按日清洗轨迹（剔除速度突变漂移点、低精度点、长时间静止点并抽稀）后求交；盲区热力图+按未覆盖时长排序清单；排班类自动回流强制任务池（人工不可删除）、通行受阻类推送工地协调、责任交界类上报分公司裁定；补检执行后按同一算法复算，达标销号、未达标进入下一周期并升级

---

### 页面6：爆管关阀策略生成与停气影响评估

- **view id**：`v-爆管关阀策略生成与停气影响评估`
- **终端**：PC端+指挥大屏
- **使用角色**：指挥人员、调度员
- **条款**：5.4.1

**功能模块（页面承载功能）**：事件自动触发研判；多套关阀隔离方案生成与多目标加权排序；停气影响域计算与用户清单分列；人工确认+权限校验+远程阀控执行；周边管线抢维修记录；分渠道用户告知；一键推送大屏

**关键字段/数据项**：事件信息（位置/类型/级别/触发来源）；候选方案（隔离区段、关阀清单、四目标评分：停气用户0.40/关阀数量0.20/执行耗时0.20/阀门可靠性0.20）与推荐理由；失气管段集合；居民/非居用户分列清单；重点非居用户优先告知清单；周边36个月抢维修记录及方案阀门检修史；逐座阀门执行记录与阀位反馈

**交互逻辑**：压力突降+用户报修自动触发（约3.6秒完成研判）；点选不同方案地图与右侧内容同步切换；指挥人员确认→远程阀控权限校验+二次口令→按执行顺序逐座下发关阀指令；以阀位反馈到位为唯一成功判据，超时/不到位即告警并自动派现场手动关阀任务、重算剩余方案；短信/公众号批量告知、重点非居人工电话优先；方案与影响域一键推送指挥大屏（同一份数据）

### 页面7：抢修资源配给与就近调度

- **view id**：`v-抢修资源配给与就近调度`
- **终端**：PC端
- **使用角色**：调度员
- **条款**：5.4.1

**功能模块（页面承载功能）**：抢修人员与车辆三态实时分布（30秒刷新）；按路网到达时间就近匹配；一级事件多资源组合；资源冲突抢占；指令下发与回执

**关键字段/数据项**：资源三态（空闲/在途/作业中）；实时位置；路网到达时间与直线距离对照（反例标注）；资源组合（抢修班组/应急车/阀控人员）；派单与回执记录；抢占记录

**交互逻辑**：资源状态由派单、到场回执、工单办结三个业务动作自动驱动，不设人工改状态入口；事件后调用路网服务按到达时间升序排候选（作业中不参与）；确认派单经APP+短信双通道下发；接单转在途并回传轨迹、到场回执留预计与实际到达；高级别事件按级别抢占资源并自动为被抢占事件改派次优

---

### 页面8：共性隐患研判（AI聚类与NLP）

- **view id**：`v-共性隐患研判-AI聚类与NLP-`
- **终端**：PC端
- **使用角色**：安全管理人员
- **条款**：5.4.1

**功能模块（页面承载功能）**：工单文本预处理（燃气领域词表分词+停用词过滤）与密度聚类；簇特征四维刻画；大模型根因分析+事实校验；管理建议分类输出

**关键字段/数据项**：高频共性问题榜单（按簇内工单数排序）；簇特征（时间/空间/对象/复发四维）；根因结论（每项数值回链具体工单集合）；管理建议（制度/流程/标准/技术四类+责任部门）；复核命名与标注回流记录

**交互逻辑**：按周期抽取近12个月工单备注与处置说明；密度聚类自动定簇数、单簇<10单不成簇；安全人员复核簇的业务含义并命名，结论回流为标注样本；点击结论数值展开对应工单清单核对；大模型仅组织表述、不得生成工单中不存在的事实，校验不通过不予输出；建议采纳转待办并纳入下期报告复评

### 页面9：运营策略生成与决策报告推送

- **view id**：`v-运营策略生成与决策报告推送`
- **终端**：PC端
- **使用角色**：各级管理人员
- **条款**：5.4.1

**功能模块（页面承载功能）**：低效环节规则识别（指标阈值比对）；决策报告模板生成（运行概况/低效环节/提升建议/下月重点+指标附表）；大模型组织表述+事实校验；PDF/Word双格式推送与阅读记录

**关键字段/数据项**：低效识别指标与阈值（复核等待>3天、盲区清零率100%、隐患复发率3%、计划按期执行率95%、一次办结率90%）；报告四节结构与附表；五项留痕（数据快照、规则版本、模型版本、事实校验结果、人工修订前后对照）；推送对象/频次/阅读情况

**交互逻辑**：低效环节由规则触发而非大模型判断，触发规则与命中数值留痕；指标自动填充、建议由大模型按模板组织；数值事实校验不通过不发布；管理层审阅修订并留前后对照；月报每月1日推送集团与分公司、周报每周一推送站长及以上、一级事件后24小时专题报告；建议一键转待办并下期自动复评执行情况

## 原型实现要求

- 顶部 module-top：模块名 + 优先级徽标 + segmented control 切换各页面 view
- 地图/GIS 一律用 .map-canvas CSS 示意（网格底+彩色管线+点位），禁外网地图
- 演示数据用真实感中文数据（管段GD-XXXX、工单号、脱敏姓名），基数与调研一致
