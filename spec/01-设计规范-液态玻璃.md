# 设计规范 —— Apple Liquid Glass（苹果液态玻璃）

> 全局唯一设计系统，所有模块原型必须通过 `styles/liquid-glass.css` 引用；禁止模块内另起配色体系。

## 1. 设计语言

iOS 26 Liquid Glass：**半透明磨砂玻璃面板悬浮于彩色氛围之上**。玻璃有材质感（模糊+饱和度提升+边缘高光+柔和投影），内容像放在一层「会呼吸的冰」上。整体明快、通透、轻盈。

- override 声明：本规范为用户指定的 Apple Liquid Glass 设计系统。允许使用玻璃拟态渐变氛围背景与 SF Pro 替代字体（Outfit）；**紫色系（purple/violet/indigo/fuchsia）仍然禁止**；图标一律使用 FontAwesome，禁止 emoji 图标。

## 3. 氛围背景（body 级）

固定视口的彩色光斑网格（浅色系，避开紫色）：

```css
body {
  background: #EAF4F8;
}
body::before, body::after {
  content: ''; position: fixed; z-index: -1; border-radius: 50%; filter: blur(90px);
}
body::before { width: 48vw; height: 48vw; left: -12vw; top: -14vw; background: #BFE7F0; }
body::after  { width: 42vw; height: 42vw; right: -10vw; bottom: -12vw; background: #C8EDDA; }
```

另加一个 `.ambient-blob`（暖沙色 #FBE8CE，右上），每个模块页只需一个 `<div class="ambient-blob"></div>`。

## 4. 字体

```css
font-family: 'Outfit', 'PingFang SC', 'HarmonyOS Sans SC', 'Microsoft YaHei', sans-serif;
/* 数字/编码：'DM Mono', monospace —— 用于单号、得分、坐标 */
```

字号：页面大标题 20px/700 · 区块标题 15px/600 · 正文 13px · 辅助 12px · 统计卡数值 28px/700（DM Mono）。

## 6. 交互约定

1. **页面视图切换**：每个模块页为单文件多视图。`<section class="view" id="v-xxx">` 默认第一个显示；`switchView('v-xxx')` 切换并更新 segmented 状态 + location.hash；`hashchange` 支持从主框架深链进入（`modules/m01-map.html#v-heatmap`）。
2. **弹窗**：`openModal('id')` / `closeModal('id')`；弹窗 HTML 必须放在对应 view 内部；遮罩点击可关闭。
3. **红色阻断类交互**（合规阻断、强制插入移出等）必须做成模态遮罩 + 仅两条出路按钮，体现「不可绕过」。
4. **演示数据**：全部用真实感中文演示数据（管段号 GD-XXXX、工单号、姓名脱敏如 王*强）；统计数字与调研基数一致（管网10815km、巡检员178、抢修员123、前100条清单等）。
5. **地图**：一律 CSS/SVG 示意（网格底 + 彩色折线代表管线 + 点位圆标），禁止外网地图 API。
6. **图标**：FontAwesome 6 CDN（模块页与主框架统一引入），禁 emoji。

## 7. 布局

- 模块页：`.module-wrap`（max-width 1440，margin auto）→ `.module-top`（模块名+徽标+seg）→ views
- 内容栅格非对称：统计行 `grid-template-columns: repeat(4, 1fr)` 或 `1.2fr .9fr .9fr 1fr` 错落；主内容 2:1（`grid-template-columns: 2fr 1fr`）
- 手机框场景：左 PC 说明/看板 + 右 phone-frame 并排（`grid-template-columns: 1fr 400px`）
