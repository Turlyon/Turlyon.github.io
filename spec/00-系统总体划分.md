# 杭州燃气 · 管网运营智能体平台 —— 系统总体划分

> 原型总体架构 spec · 依据《管网运营场景页面清单.xlsx》（12 模块 / 70 页面）与 2026-10 调研报告

## 1. 平台定位

面向杭州燃气管网运营场景的 **AI 智能体集群平台**，覆盖「态势总览 → 风险评估 → 巡检作业 → 管道保护 → 应急处置 → 设备管理 → 运营效能」全链路。智能体不另建业务系统，以接口调用、页面嵌入、消息推送三种形态长在既有系统（巡检抢修指挥系统 / 外勤APP / GIS）之上。

## 2. 终端形态

| 终端 | 呈现方式 | 说明 |
|------|---------|------|
| PC 端（工作台） | 标准内容区布局 | 运行站/技术部/设备部日常使用 |
| 指挥大屏 | 深色玻璃、大字号指标卡 | 调度中心、公司层汇报 |
| 调度台 | PC 布局 + 高频弹窗流 | 调度员，1 秒弹窗推荐等 |
| 外勤 APP | 页面内嵌「手机框」（mobile frame）模拟 | 巡检工、抢修工现场作业 |

## 6. 模块页通用骨架

- 顶栏：模块名 + 页面切换 segmented control（对应模块内多个页面）+ 模块优先级徽标
- 页面视图：同一 HTML 内 `data-view` 切换，URL hash `#view=xxx` 支持主框架深链
- 内容：统计卡行 → 筛选/工具条 → 主内容（表格/地图占位/流程卡）→ 弹窗组
- APP 视图：`<div class="phone-frame">` 内呈现移动端界面
